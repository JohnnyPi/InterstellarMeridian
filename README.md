# Interstellar Meridian

*Chart your own course.*

Interstellar Meridian is an independent, open-source spacefaring simulation built with Rust and Bevy.

Set within a distant galaxy inhabited by seven human civilizations, the game places players in a persistent, evolving universe where commerce, exploration, warfare, diplomacy, and discovery are interconnected.

**A universe that acts without you, reacts to you, and gives you reasons to care.**

## Design goals

- A richly interconnected, persistent living universe.
- Responsive and satisfying spaceflight.
- Dynamic economies, production chains, and logistics.
- Autonomous factions and meaningful conflict.
- Consequential exploration and discovery.
- Open-ended careers and player progression.
- Fleet ownership and capital ship command.
- Data-driven content and native modding.
- A vibrant, original visual identity.

## Technology

- Language: Rust
- Game engine: Bevy
- Primary development platform: Windows x64
- Architecture: Modular, ECS-oriented, with headless simulation support
- Version control: Git

## Development status

**Pre-alpha — Project Establishment**

Interstellar Meridian is currently establishing its design documentation and technical foundation. Gameplay features described in the design goals are planned capabilities, not implemented functionality.

## Documentation

Project design documents, architectural specifications, worldbuilding references, decision records, and implementation plans are maintained in the `docs/` directory.
